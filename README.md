## 📌 Description

This project is a basic Spring Boot application that demonstrates how to set up a REST API and create a simple endpoint. It serves as a starting point for building more complex Spring Boot applications.

## 🚀 What it does

* Runs a Spring Boot application
* Exposes a REST endpoint (`/hello`)
* Returns a simple "Hello Spring Boot!" response
* Configured with a custom server port (9090)

## 🎯 Purpose

This project is created to understand:

* Spring Boot project structure
* REST controller basics
* Application configuration
* Running a Spring Boot application locally and via Docker

## 🛠 Tech Stack

* Java 17
* Spring Boot
* Maven
* Embedded Tomcat
* Docker

## 📌 Endpoint

GET `/hello` → Returns a welcome message

## 💡 Note

This is a beginner-friendly project and serves as a foundation for building more advanced applications like CRUD APIs and microservices.
